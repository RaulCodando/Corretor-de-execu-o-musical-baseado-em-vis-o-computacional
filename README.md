# Corretor de postura para violonistas baseado em computer vision
Sistema baseado em visão computacional e aprendizagem de máquina para avaliação de postura e posicionamento de violonistas em tempo real.

Este projeto utiliza matplotlib para a criação e treinamento do modelo classificador, YOLO para detecção e métrica do violão e mediapipe para a detecção e estimativa da postura e posicionamento de mãos e dedos do violonista.
